Buscar carta por nombre

Escribí el nombre (en inglés funciona mejor, la base de datos es de TCG en inglés) y buscá en la base de datos de Pokémon TCG. Si agregás el número de la carta al final (ej: "Tapu Koko 67"), filtra directo esa versión exacta dentro del set.

Escanear una foto

Subí una foto de tu carta. Se usa un modelo de visión para identificarla y luego se busca en la base de datos oficial. Funciona mejor con buena luz y la carta bien encuadrada.

🎲 Mazos automáticos desde tu colección

Genera dos mazos posibles usando tus Pokémon con más copias (o mejor tipo) como núcleo, sumando su preevolución si la tenés, y completando con cartas de soporte típicas (Ultra Ball, Professor's Research, Switch, energía básica del tipo correspondiente, etc).

Aviso: como no tengo el meta competitivo actualizado de julio 2026, esto usa una lógica genérica (tu Pokémon con más copias/mejor tipo como atacante + su preevolución si tiene + soporte estándar), no son listas de torneo. Para eso, seguí usando Limitless TCG.
